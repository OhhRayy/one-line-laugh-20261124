## What it does

`main.py` writes one funny line to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The line:

> I bought a plant to prove I could keep something alive; it died, and now the plastic one judges me.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
